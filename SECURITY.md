# Security and privacy

SENTINEL is an experimental computer-vision prototype, **not** a production authentication or access-control system.

Do not submit real facial images, biometric embeddings, credentials, or other personal information in issues or pull requests. Please report security vulnerabilities privately using GitHub private vulnerability reporting if the repository has enabled it. Avoid disclosing exploitable details publicly before coordination.

Model files and training datasets are excluded from this repository. Face embeddings are biometric data and require appropriate protection and lawful processing.
